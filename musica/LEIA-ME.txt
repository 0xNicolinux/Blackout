Coloque as faixas MP3, OGG, WAV, M4A, AAC ou WebM nesta pasta.

No GitHub Pages, o rádio carrega automaticamente as faixas listadas em playlist.json.
Quando novas músicas forem enviadas para esta pasta, a automação atualiza a lista e o
script do jogo. Ligue o rádio e insira a fita do estagiário; use os botões para trocar
as faixas. O áudio começa após a interação do jogador, conforme as regras do navegador.

Para abrir localmente, use um servidor HTTP (por exemplo, ABRIR JOGO.bat). Abrir o HTML
diretamente como file:// bloqueia o carregamento automático de arquivos por segurança.
